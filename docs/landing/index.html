Cloudflare Agents SDK

Agents that persist, think, and act at the edge

A framework for stateful AI agents on Cloudflare's network. Each agent keeps its own state, talks over HTTP and WebSockets, schedules its own work, and hibernates when idle.

Your first agent

One class. State, transport, and schedule included.

Extend Agent, implement the handlers you need, and the runtime takes care of instance identity, storage, and wake-up.

src/agent.ts TypeScript 
import { Agent } from "agents";

export class IntelligentAgent extends Agent {
  async onRequest(request: Request) {
    return new Response("Ready to assist.");
  }

  async onConnect(connection) {
    connection.send(JSON.stringify(this.state));
  }

  async evolve(newInsight) {
    this.setState({
      ...this.state,
      insights: [...(this.state.insights || []), newInsight]
    });
  }

  async initialize() {
    this.schedule(10, "quickInsight", { focus: "patterns" });
    this.schedule("0 0 * * *", "dailySynthesis");
  }
}

  1. A request or connection arrives

    Route by name with getAgentByName or create a fresh instance. The same agent answers HTTP and WebSocket traffic.

  2. State updates and syncs

    setState persists to SQLite-backed storage and fans out to every connected client through onStateUpdate.

  3. Work is scheduled

    schedule accepts a delay in seconds, a cron expression, or a Date. Callbacks are ordinary methods on the class.

  4. The agent hibernates

    Idle agents release compute and wake on the next message, request, or scheduled task, with state intact.

What ships in the package

Everything an agent needs to stay alive

Persistent state

Each agent owns a durable, SQLite-backed state object. Updates are broadcast to connected clients and delivered to your handler with their source.

setState()onStateUpdate()

HTTP and WebSockets

Handle one-shot requests and long-lived connections from the same class. Connections survive across messages without extra plumbing.

onRequest()onConnect()onMessage()

Scheduling

Schedule a method by delay, cron expression, or absolute date. The agent wakes to run it even if nothing else is connected.

schedule(10, …)schedule("0 0 * * *", …)

React hooks

Connect a component to an agent, subscribe to state, and send messages with one hook. A vanilla client covers everything else.

useAgent()AgentClient

AI chat, streamed

AIChatAgent stores message history and streams model output through the Vercel AI SDK. Pair it with the matching React hook for a working chat UI.

onChatMessage()useAgentChat()

MCP server and client

Expose tools to AI assistants over the Model Context Protocol, or consume tools from other MCP servers inside the same agent.

agents/mcp
